# Planificació prèvia del projecte

Aquest document recull la planificació del projecte i les responsabilitats de cadascun dels membres de l’equip.

## 1. Objectiu del projecte

Desenvolupar un joc web de preguntes tipus Quiz amb HTML, CSS i JavaScript. El joc s’executarà localment en un navegador i no necessitarà cap servidor.

Inclourà una pantalla de benvinguda, selecció de categoria, preguntes amb diverses opcions de resposta, un temporitzador i una pantalla final amb els resultats.

## 2. Repartiment de rols

- **Bruno:** Lògica del joc amb JavaScript.
- **Isaac:** Disseny i estructura de la interfície web.
- **Sergi:** Contingut i preguntes.
- **Pol:** Coordinació i gestió de GitHub.

## 3. Responsabilitats

- **Bruno:** Implementar la lògica del joc com per exemple: mostrar les preguntes i les opcions, validar les respostes, calcular la puntuació i gestionar el temporitzador.
- **Isaac:** Crear l’estructura i el disseny de la pàgina web amb HTML i CSS, i adaptar la interfície a diferents mides de pantalla.
- **Sergi:** Crear les categories, les preguntes i les opcions de resposta, i comprovar que les respostes correctes siguin fiables.
- **Pol:** Crear i mantenir el repositori de GitHub, organitzar les tasques i donar suport a l’equip en l’ús del repositori. També participar en el desenvolupament del projecte.

## 4. Fases i tasques

1. Revisar els requisits del joc i acordar-ne les funcionalitats.
2. Preparar el mockup de les pantalles principals.
3. Crear l’estructura inicial dels fitxers del projecte.
4. Desenvolupar la interfície i la lògica del joc.
5. Afegir les preguntes i les categories.
6. Provar el joc i corregir errors.
7. Revisar el projecte i completar-ne la documentació.

## 5. Metodologia de treball

Utilitzarem la metodologia **Kanban** per organitzar i fer el seguiment de les tasques. Les distribuirem en un tauler amb aquestes columnes:

- **Per fer**
- **En curs**
- **En revisió**
- **Fet**

## 6. Organització del repositori

El repositori de GitHub contindrà el codi font, els recursos del projecte i la documentació. L’equip farà commits periòdics i utilitzarà branques i Pull Requests per revisar i integrar els canvis.

## 7. Execució del joc

Per jugar, caldrà obrir el fitxer `index.html` amb un navegador web. Inicialment, el joc s’executarà localment i no estarà allotjat en cap servidor, tot i que no es descarta allotjar-lo més endavant.
